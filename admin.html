Provisioning controls

Server-enforced hierarchy

Platform admins can provision state and district administrators. State admins can provision district admins, supervisors and workers. District admins can provision supervisors and workers only within their district.

No self-elevation

Role, status and geographic scope are validated from the authenticated database profile. Browser metadata is never used as authority.

Auditable changes

Successful invitations create a provisioning audit record. Partial failures trigger account suspension and rollback.
